# AI in everyday life

AI features are often embedded in familiar products. They can help people find information, reduce repetitive work, and make digital services easier to use.

| Area | Example | What to keep in mind |
| --- | --- | --- |
| Accessibility | Captions and speech-to-text | Review names and specialized vocabulary |
| Search | Ranking relevant results | Results can reflect gaps in the source data |
| Healthcare | Supporting image review | Qualified clinicians remain responsible for care |
| Software | Drafting or explaining code | Test generated code before relying on it |
| Customer support | Routing common questions | Provide a clear path to a person |

## Responsible use

Before using an AI feature, consider:

- **Accuracy:** How will mistakes be detected and corrected?
- **Privacy:** Is sensitive information being shared or retained?
- **Fairness:** Does it work reliably for the people affected?
- **Transparency:** Can users tell when AI is involved?
- **Human oversight:** Who can review and appeal consequential outcomes?

AI works best as a tool that supports informed human judgment, not as a substitute for accountability.
